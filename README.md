# Home Assistant Apps

This repository contains my Home Assistant Apps (formerly called "add-ons").

## [JS/TS Automations](ha_js_automations/README.md)

Create Home Assistant automations using JavaScript or TypeScript. Provides a full development environment with VSCode web editor integration, TypeScript support, and hot-reload for automation scripts.

### Key features

- TypeScript/JavaScript support with a type-safe API
- VSCode web editor integration
- Hot-reload of scripts when files change
- Multi-architecture support (ARM and x86)
